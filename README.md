### 🔬 PCBDefect-X — Deep Learning & Computer Vision `Research`
`Python · PyTorch · OpenCV · RF-DETR · ONNX Runtime · TensorRT · FastAPI · Next.js` · *May 2026 – Present*
[🌐 Live](https://pcb-defect-x.vercel.app) · [💻 GitHub](https://github.com/AsjidSiddique/PCBDefect-X) · [📄 Research](https://pcb-defect-x.vercel.app/research)

End-to-end system for **automated PCB defect detection and localisation** on the DeepPCB dataset with **RF-DETR Nano** — deterministic dataset conversion, train/val/test splits, augmentation, config management, and deployment via **ONNX Runtime and TensorRT FP16** with parity validation and smoke checks.

| Test images | Defect classes | mAP@50 | mAP@50:95 | Precision | Recall | F1 |
|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| **366** | **6** | **78.8%** | **39.3%** | **90.0%** | **74.8%** | **81.4%** |

### 🛡️ FraudShield — Machine Learning & Explainable AI `Research`
`Python · scikit-learn · PyTorch · SHAP · Pandas · NumPy · FastAPI · Next.js` · *Jun – Aug 2026*
[🌐 Live](https://fraudshield-sable.vercel.app) · [💻 GitHub](https://github.com/AsjidSiddique/Fraudshield) · [📄 Research](https://fraudshield-sable.vercel.app/research)

Explainable fraud detection on **284,807 transactions (~0.17% fraud)**. Train-only preprocessing and an untouched final test set prevent data leakage; thresholds are optimised on validation data. Compared **Logistic Regression, Random Forest, HistGradientBoosting and a PyTorch MLP** (ROC-AUC, PR-AUC, precision, recall, F1), selected **Random Forest**, and added **SHAP explanations** behind a FastAPI inference service.

| PR-AUC | Precision | Recall | F1 |
|:-:|:-:|:-:|:-:|
| **0.803** | **86.9%** | **76.8%** | **81.6%** |
